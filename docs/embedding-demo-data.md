# 임베딩 검색 시연 데이터

24개 글은 실제 조리 경험이 아닌 시연용 가상 후기다. 평점용 대량 후기를 게시판에 복사하지 않는다.

현재 제공자는 `local-ngram`으로, 문장 뜻을 이해하는 신경망 모델이 아닌 단어·글자 유사도 기반이다. 동의어 일부와 표현 변형은 찾을 수 있지만 간접 표현이나 부정문을 정확히 구분하지 못할 수 있다. 아래 검색 결과가 낮으면 테스트 데이터를 검색어에 맞춰 고치지 말고 그 한계를 기록한다. 검색은 키워드 60% + 벡터 40%이므로 상위에 나온다는 사실만으로 의미 이해를 입증하지 않는다.

|글|제목|확인용 검색어|
|---|---|---|
|E01|계란말이가 찢어진 이유를 찾았어요|계란말이 안 찢어지게 만드는 법|
|E02|퍽퍽한 닭가슴살을 촉촉하게 먹기|닭고기가 너무 퍽퍽해요|
|E03|두부 표면에 바삭한 껍질 만들기|겉바속촉 두부 부침|
|E04|두부를 갈아서 만든 부드러운 수프|씹기 편하고 속 편한 아침식사|
|E05|우유 없이 크림 느낌을 낸 파스타|유제품 못 먹는 사람의 고소한 면 요리|
|E06|치즈와 생크림을 넉넉히 넣은 파스타|진한 생크림 베이컨 파스타|
|E07|고기 대신 버섯으로 만든 덮밥|동물성 재료 없는 쫄깃한 덮밥|
|E08|소고기를 센 불에 짧게 볶았어요|질기지 않은 쇠고기 볶음|
|E09|불 앞에 서기 싫은 날의 차가운 면|더운 날 가스레인지 안 쓰는 한 끼|
|E10|전자레인지로 끝낸 5분 달걀밥|설거지 적고 금방 만드는 혼밥|
|E11|주말에 시간을 들인 라구 소스|오래 끓여 맛이 깊어진 토마토 소스|
|E12|도시락 반찬을 한 번에 소분하기|평일 점심 미리 준비하는 식단|
|E13|냉동 만두는 해동하지 않고 구웠어요|얼린 만두 피가 팬에 붙어요|
|E14|냉동 고기를 천천히 녹여 본 후기|얼린 돼지고기 다음 날 쓰기|
|E15|남은 치킨을 다시 바삭하게|어제 먹던 튀김 바삭하게 데우기|
|E16|볶음밥은 갓 지은 밥보다 찬밥|볶음밥이 질고 덩어리져요|
|E17|아이와 나눠 먹은 순한 떡볶이|맵지 않게 아이와 같이 먹는 떡 요리|
|E18|고춧가루 향을 살린 매콤한 찌개|칼칼하고 매운 김치 국물|
|E19|식비를 아낀 콩나물 한 봉지|돈 적게 들고 두 끼 먹는 자취 메뉴|
|E20|손님 오는 날 준비한 스테이크|손님 초대용 특별한 소고기 요리|
|E21|밀가루 대신 감자전분을 사용한 전|밀가루 빼고 만드는 쫀득한 부침|
|E22|묵은 채소를 채운 달걀 오믈렛|남은 야채 조금씩 한꺼번에 처리|
|E23|오트밀을 짜지 않게 끓인 아침|담백하고 부드러운 따뜻한 죽|
|E24|설탕을 덜 넣은 바나나 간식|시럽이나 설탕 없이 달콤한 간식|

혼동 사례: E03/E04(두부 식감), E05/E06(유제품 사용 여부), E07/E08(육류 여부), E10/E11(조리 시간), E17/E18(맵기), E19/E20(예산). 정확 일치 검색과 간접적인 표현을 각각 시도해 Top 5에서 비교한다.
