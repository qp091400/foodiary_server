# 추천 레시피 더보기

`POST /fridges/{id}/recipes/recommendations`는 기본 30개씩 돌려줍니다.

첫 요청: `{"item_ids": [1, 2]}`

응답에 `seed`(이번 추천의 랜덤 순서)와 `next_offset`(다음 페이지 위치)이 추가됩니다. `next_offset`이 null이면 마지막입니다.

추가 요청: 같은 item_ids와 받은 seed, next_offset을 `{"item_ids": [1, 2], "seed": 1234, "offset": 30}`처럼 보냅니다. 매 요청 권한과 현재 식품 상태를 다시 확인하고, 별점도 해당 페이지의 레시피만 조회합니다.

같은 seed에서는 요리별 대표 레시피와 페이지 경계가 유지됩니다. 추가 재료가 적은 순서를 우선하며, 동순위는 추천 세션별로 섞습니다. SQLite 자료와 JSON 자료를 모두 지원합니다. 새 선택에서는 offset과 seed를 생략해 새 순서를 받습니다. 자료 자체가 교체되거나 선택 식품이 변경되면 첫 페이지부터 다시 조회합니다.

앱은 목록 끝의 버튼을 누를 때만 다음 페이지를 요청합니다. 실패하면 기존 목록을 유지하고 같은 페이지를 재시도합니다. 평점 변경 시에는 추천을 다시 뽑지 않고 해당 카드의 별점만 갱신합니다.
